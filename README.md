# Phantom Shooter

Phantom Shooter 是一个桌面 Web FPS 原型。项目使用 Vite、TypeScript、Three.js 和 Rapier，所有场景、武器与音效均由程序生成，不依赖外部游戏资源。

## 环境要求

- Node.js 20.19+ 或 22.12+
- 桌面版 Chrome / Edge

## 本地运行

```bash
npm install
npm run dev
```

打开终端中显示的本地地址，在启动界面选择关卡即可进入。游戏中按 `Esc` 暂停后可继续或切换关卡。

## 构建与预览

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`，可部署到任意静态网站托管服务。由于浏览器 Pointer Lock 和音频策略，请通过 HTTP 服务访问，不要直接双击打开构建后的 HTML。

## GitHub Pages 自动部署

仓库包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 分支后，GitHub Actions 会自动安装依赖、构建项目并部署 `dist/`。也可以在仓库的 Actions 页面手动运行该工作流。

首次使用时，需要在 GitHub 仓库中进入 **Settings → Pages**，将 **Build and deployment → Source** 设置为 **GitHub Actions**。部署成功后的地址为：

```text
https://dairuidenny.github.io/phantom-shooter/
```

Pages 子路径配置位于 `vite.config.ts`；如果仓库改名，需要同步修改其中的 `base`。

## 操作

- `WASD`：移动
- `Shift`：冲刺；空中会保留冲刺动量并可适度修正方向
- `Space`：跳跃
- 鼠标：控制视角
- 鼠标左键：全自动射击
- 鼠标右键：瞄准
- `R`：换弹
- `E`：开始录制；录制0.5秒后可再次按下提前结束，最长4秒
- `F`（按住）：进入最长2秒的子弹时间；松开或到时退出，若准星正对分身则执行取代
- `Q`：充能达到200点后，在非录制状态下一次引爆全部虚影
- `Esc`：释放鼠标

最多保留3个循环回放的虚影；录制会优先使用空缺槽位，槽位全满后再按顺序覆盖最早的虚影。录制与子弹时间互斥。子弹时间内除镜头操控外，角色、敌人、武器、分身回放与特效均以0.2倍速度推进；技能最多维持2秒，退出后进入8秒冷却。子弹时间内所有分身会显示不受遮挡的白色粗轮廓，被准星瞄准时轮廓变为橙色；瞄准检测忽略敌人与场景遮挡。退出瞬间若准星瞄准橙色虚影，本体会快速突进至其位置，到位后虚影消失并释放对应槽位。突进无视碰撞，速度为原取代移动速度的2倍；突进期间，位于玩家前方、半径为玩家半径2倍的球形判定会对途径的每个敌人造成一次20点伤害，伤害无视护盾并参与仇恨判定，击杀会使敌人朝远离玩家的方向倒下。玩家本体或分身每次枪械命中增加1点引爆充能，达到200点且场上存在虚影时按 `Q` 会消耗全部充能并引爆；爆炸命中不会增加充能。项目枪械采用即时命中的 hitscan，因此子弹时间缩放射速、枪械表现、曳光和命中特效，不引入额外弹丸飞行时间。移动、镜头和武器的主要参数集中在 `src/config.ts`，便于后续调节手感。

## 关卡

- **热身靶场**：移动与射击训练场。命中靶面会显示伤害飘字；普通区域增加1点引爆充能但不显示充能飘字，中央白色圆形区域增加10点并显示充能奖励飘字。
- **守护尖塔**：保护中央方尖碑。每波可从周围12个刷新点独立配置敌人和启动延迟；同一波内的刷新点并行计时，延迟结束后各自以固定每秒10个敌人的速度生成。玩家与分身枪械均可伤害敌人，引爆分身还会造成大范围爆炸伤害和击飞。方尖碑生命耗尽后可重新挑战或切换关卡；有限波次模式下，最后一波全部敌人的死亡动画结束后进入胜利界面。

### 波次配置视图

Locus 中的 **守护尖塔波次配置** 视图可编辑每波12个刷新点的敌人类型、数量、启动延迟，以及敌人的形状、宽高、移速、血量、对塔攻击力和击杀奖励充能。奖励留空时按0处理。“无限波次”默认关闭；开启后，第N波结束后会持续复用第N波配置。点击“应用配置”会更新 `src/defense-config.ts`。
